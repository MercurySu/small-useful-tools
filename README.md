# Small Useful Tools

**免费、免安装、可直接在浏览器中使用的小工具集合。**  
A growing collection of small, free browser-based utilities.

**在线体验 / Live website:** https://mercurysu.github.io/small-useful-tools/

## 已发布工具 / Available tools

### [全屏纯色屏幕 · Fullscreen Color Light](https://mercurysu.github.io/small-useful-tools/color-light.html)

自由选择纯色光，让电脑或手机屏幕显示你想要的颜色。

- 通过可视化颜色盘选色，或输入 HEX 色号
- 调整颜色盘明度
- 一键显示全屏纯色；电脑按任意键返回，移动设备点击屏幕返回
- 可用于临时屏幕补光、摄影背景、桌面氛围光及简单的纯色显示检查

Pick a color on the wheel or enter a HEX code, then display that color fullscreen. Useful for ambient lighting, temporary screen fill light, photo backgrounds, and simple solid-color display checks.

> 注意：实际亮度和颜色取决于设备屏幕。本工具并非专业色彩校准工具。  
> Note: Light output and color accuracy depend on your display; this is not a professional calibration tool.

## 如何使用 / How to use

直接打开 [在线工具箱](https://mercurysu.github.io/small-useful-tools/)，选择需要的工具；无需安装或注册。

Open the [tool collection](https://mercurysu.github.io/small-useful-tools/) and select a tool. No download or account required.

## 技术实现 / Tech

纯静态 HTML、CSS 和 JavaScript，通过 GitHub Pages 托管。  
Built with static HTML, CSS and JavaScript, hosted on GitHub Pages.

## 增加新工具 / Adding tools

新的静态工具可以作为单独的 `.html` 文件加入仓库，并在 `index.html` 中添加链接，同时维护 `sitemap.xml`。
